# Club website

Plain HTML pages with one shared stylesheet. No build step, no framework.

- `index.html`: home page (the poster)
- `about.html`: about the group
- `poster.html`: redirects to the homepage (old link)
- `events.html`: meetings
- `resources.html`: reading list and links
- `contact.html`: contact info
- `style.css`: shared styles (placeholder only)
- `CNAME`: tells GitHub Pages to serve the site at aisafety.josefely.net. Don't delete it.

To edit: change the files, commit, and push to `main`. GitHub Pages republishes in a minute or two.

To preview locally: open `index.html` in a browser.

Text in [square brackets] is a placeholder.
